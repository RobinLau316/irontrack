# 训练次数行内输入设计

## 目标

修复“训练中”页面调整次数后偶发显示 `NaN` 的问题，并允许用户点击次数数字直接输入。

## 交互

- 次数数字显示为行内数字输入框，视觉上保持现有数字样式。
- 点击数字后可直接输入非负整数。
- 按回车或输入框失去焦点时确认。
- 左右按钮继续保留，每次减少或增加 1，最低为 0。
- 空值、`6-8`、非数字、小数等无效输入不写入训练状态；确认时恢复到修改前的有效次数。

## 范围

- 只修改当前 GitHub Pages 实际发布的 `index.html`。
- 只改变“次数”交互，不修改重量、组数、训练流程或页面布局。
- 不改变任何 `localStorage` 存储键或既有数据结构。

## 数据边界

发布不会主动删除用户浏览器中已有的个人资料和历史数据。当前尚未持久化的训练中间状态，在刷新页面后仍可能丢失，本次不扩展处理。

## 验收

1. 点击次数数字，可以直接输入有效整数。
2. 点击 `+` 或 `-`，次数稳定变化 1。
3. 输入空值、`6-8`、字母或小数后，不出现 `NaN`。
4. 重量、组数及原有本地数据不受影响。
5. 推送 `main` 后由现有 GitHub Pages 工作流自动发布。
