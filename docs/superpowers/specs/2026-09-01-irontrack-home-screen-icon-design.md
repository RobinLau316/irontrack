# IronTrack iPhone 主屏幕图标整改设计

日期：2026-09-01  
状态：已实现、验收并上线  
对应 PRD：`docs/superpowers/specs/2026-08-28-irontrack-prd.md` 第 9.1、14.2、14.3、14.10 节

## 1. 问题与原因

用户在 iPhone Safari 中把网页添加到主屏幕后，桌面图标显示为一根竖棍，无法体现 IronTrack 的品牌和健身属性。

当前发布入口没有声明 iPhone 专用的 `apple-touch-icon`，网页引用的还是空白内嵌清单；项目中的实际清单没有被页面使用，清单引用的图标文件也不存在。iPhone 因而只能使用自动生成的网页缩略图或缓存结果，无法稳定显示预期图标。

## 2. 已确认的视觉方案

- 采用用户选择的 B 方案“力量杠铃”。
- 图标为近黑色方形底，主体为荧光绿色简化杠铃，中央保留小面积暖白圆心。
- 风格沿用现有“午夜竞技”视觉体系，不增加新的品牌主色。
- 图形保持粗壮、居中和高对比；不在图标内放置 `IRONTRACK` 小字。
- 四周保留足够安全距离，系统裁成圆角方形或遮罩图标时不得切掉杠铃片。

## 3. 技术与资源规格

- 提供 `180×180` PNG，供 iPhone 添加到主屏幕时使用。
- 提供 `192×192` 与 `512×512` PNG，供 Web App 清单和其他设备使用。
- 额外提供适合系统遮罩裁切的 `512×512` maskable PNG；关键图形位于中央安全区。
- 页面直接引用真实的 `manifest.json`，并显式声明 `apple-touch-icon`。
- 清单中的入口和资源使用适配 GitHub Pages 子目录部署的相对路径，不使用站点根路径。
- `theme_color`、`background_color` 与当前近黑界面统一。
- 应用短名称为 `IronTrack`，以该名称显示在主屏幕图标下方。

## 4. 数据与功能边界

- 本次只修改网页元信息、Web App 清单、图标资源和静态检查。
- 不修改本地存储键、训练数据结构、训练历史、计划、进行中训练或 API Key。
- 更换图标不触发数据迁移，也不要求清空浏览器数据。

## 5. iPhone 使用步骤

1. 用 Safari 打开 IronTrack 正式网址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 确认名称为 `IronTrack`，点击“添加”。

如果主屏幕已经存在旧图标，需要先删除旧图标，再从 Safari 重新添加。iOS 会缓存已安装的主屏幕图标，仅刷新网页通常不会替换旧图标；删除主屏幕快捷方式不会删除 Safari 中的 IronTrack 本地训练数据。

## 6. 验收标准

1. iPhone Safari 新增到主屏幕后，显示完整的近黑底荧光绿杠铃图标，不再显示竖棍或网页缩略图。
2. 图标在 iPhone 圆角裁切后仍居中、完整、清晰，不出现透明边、白边或杠铃片被裁掉。
3. 主屏幕图标下方显示 `IronTrack`。
4. 从主屏幕打开后以独立 Web App 方式显示，主题色与现有“午夜竞技”界面一致。
5. 清单和全部图标资源在线可访问；静态检查能够发现图标缺失、尺寸错误或错误引用。
6. 修改前后的本地个人资料、训练计划、历史记录和进行中训练保持不变。

## 7. 发布与验证

- 修改提交到 `main` 后由现有 GitHub Pages 流程发布。
- 发布完成后检查正式网址的页面元信息、清单和全部图标资源。
- 使用全新安装或删除旧图标后重新添加的方式完成 iPhone 实机验收。

2026-09-01 已完成网页声明、应用清单、四套图标资源和静态检查更新，并由 GitHub Pages 成功发布。线上 `apple-touch-icon.png` 返回 `200`，尺寸为 `180×180`，文件校验值与本地验收资源一致。iPhone 主屏幕最终显示效果仍需按第 5 节删除旧图标并重新添加后实机确认。
