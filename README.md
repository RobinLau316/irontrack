# IronTrack

IronTrack 是一个手机优先的个人训练记录工具。它按 PPL 连续安排训练，每次只询问可用时间、疲劳和不适；可选启用 DeepSeek，按训练档案和真实记录适配当天计划。AI 不可用时继续使用本地计划。

线上地址：[https://robinlau316.github.io/irontrack/](https://robinlau316.github.io/irontrack/)

## 当前运行入口

- 线上和本地实际入口：`index.html`（样式 `public/app.css`，脚本 `public/app/`）
- 部署：推送 `main` 后由 `.github/workflows/deploy-pages.yml` 发布到 GitHub Pages
- `legacy/` 中的 Next.js 和 Tailwind 相关文件是早期原型，当前不参与线上构建

## 已实现能力

- 首次逐题建立简短训练档案，之后可更新训练方向、频率和限制
- 只询问当天时间、疲劳程度和疼痛或不适
- 根据连续数周方向、PPL 顺序和实际记录生成 6～8 个动作
- 可选启用 DeepSeek 适配计划；不启用或调用失败时使用本地规则计划
- 计划预览、自然语言调整、换动作和组数/次数/重量编辑
- 逐组确认实际训练；结束时反馈感受，部分训练可选择是否推进 PPL
- 清楚区分计划值和实际值；未确认组不计入完成训练统计
- 刷新后恢复进行中训练
- 历史、实际组数、训练时长、周频率和反馈
- 本地数据导出与导入；备份不包含 API Key
- V1.1 午夜竞技界面：首页品牌主视觉、单组专注训练页和荧光绿关键操作
- 320×568、375×667、390×844 小屏安全区适配，底部导航不再遮挡训练按钮
- 207 个精选动作、稳定编号和本地结构校验
- 新动作中文步骤、同肌群单动作替换和推拉腿结构校验
- 训练档案、实际训练记录和进行中训练均保存在本地浏览器；导入兼容 V1/V2/V3 备份

## 当前发布状态

- 阶段二已于 2026-09-03 发布并完成线上验收。
- 线上已启用 207 个精选动作、智能变式、中文动作步骤、反馈偏好与旧数据兼容。

## 本地运行

```bash
npm run dev
```

打开 `http://127.0.0.1:4173/`。

## 检查

```bash
npm run build
```

当前检查会验证页面脚本、精选动作数据、中文步骤、旧动作迁移、四种时长、6/8 动作数量、PPL 结构、AI 候选边界和数据可靠性回归。完整交互仍需按 [运行与发布手册](docs/runbook.md) 做浏览器冒烟测试。

## 数据与密钥

- 训练数据按本地用户名保存在浏览器 `localStorage`。
- DeepSeek API Key 单独保存在当前浏览器，不写入代码和普通备份。
- 清除浏览器数据会丢失本地记录，建议定期在“我的 → 本地数据备份”导出。
